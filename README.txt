SAWTI / صوتي — Arabic communication board
Open index.html in a modern browser. No installation, build process, server, or account is required. For tablets, transfer the file or host it on a trusted HTTPS static site. Browser handling of local files varies, especially on iPad; test in the actual browser. Offline operation works when the local HTML file can be opened; hosted copies are not guaranteed to load offline. Arabic speech availability depends on the browser/device; uploaded audio files work without internet. 
Tap a card to communicate. Tap Sentence to accumulate cards; use the speaker button to read the phrase. The gear opens caregiver settings. Each card accepts its own photo and prerecorded audio. Add, reorder, edit or delete cards and categories. Quick cards remain on every page. Export JSON to keep all pictures, audio and settings in one portable file; import to restore or transfer. Data stays in browser IndexedDB, which may be cleared by the browser. Back up regularly. No data is sent by this application; system speech engines may use network services. Use only images you have permission to use. This is an AAC prototype, not a medical device or a substitute for an AAC evaluation. Do not rely on it as the sole way to communicate emergencies. Caregiver settings are not password protected. Arabic seed phrases are colloquial Iraqi-style examples and can all be edited.
